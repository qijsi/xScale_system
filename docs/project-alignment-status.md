The orchestrator can run a synthetic search loop. A REAL or REPLAY enum returned by its default mock evaluator is a requested mode label, not evidence of GPU execution. Its GPU-hour budget uses heuristic estimated costs, not measured GPU-hours. Its trust score is a heuristic and may decrease; it is not a calibrated probability or a monotonicity guarantee. The adaptive controller exists separately from the orchestrator.

## Evidence boundaries

- Local integrated suites: 47 skill tests, 27 witness tests, 11 orchestrator tests (85 total), passing on 2026-10-25.
- No GPU end-to-end workflow or target-scale ranking oracle was validated in this synchronization.
- CrystalLLM motivation CSVs and plots are generated by a deterministic CPU cost model. Their `actual_latency_ms` column is synthetic, not measured training time.
- The 512-rank / 8-GPU setup, >95% Top-3 recall and 10--50x search speedup are not established xScale results. The numerical claims must not appear as completed evaluation findings.
- CEC currently equals REAL fraction minus a boundary penalty. It is not a bound on ranking-correctness probability. FIS is heuristic; topology symmetry alone does not prove substitutability under routing skew or hardware heterogeneity.

## Next milestones
